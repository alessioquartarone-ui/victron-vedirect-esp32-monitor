# Victron VE.Direct ESP32 Monitor

Public ESP32-based Victron VE.Direct monitor with WebUI, OTA updates, setup wizard, history, backup and JSON API.

## First public target

- ESP32 CYD 2.8" ILI9341
- VE.Direct RX default: GPIO27
- ESP battery ADC default: GPIO34
- WebUI setup wizard
- WiFiManager captive portal
- Configurable OTA URLs
- No private credentials or hardcoded user data

## Planned targets

- ESP32 CYD ILI9341
- ESP32 Headless / WebUI only
- ESP32-S3 Headless / WebUI only
- ESP32-S3 ILI9341
- ESP32-S3 ST7796
